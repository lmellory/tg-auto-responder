# ⚡ Telegram Автоответчик в Личные Сообщения (Userbot)

Скрипт перехватывает первое сообщение от новых заказчиков в вашем личном Telegram (`@squzzyy23`) и отправляет автоответ:

> 👋 Привет! Я сейчас занят.  
>   
> Чтобы быстрее обсудить проект, посмотреть примеры работ или рассчитать смету — переходи в мой бот-секретарь:  
> 👉 @ИмяВашегоБота  
>   
> Бот работает 24/7, поможет составить ТЗ и сразу передаст мне заявку в приоритетный список!  

### 🔒 Ключевые правила:
* **Отвечает ТОЛЬКО на 1-е сообщение от новых людей.**
* Никогда не пишет повторно тем, кому уже ответил.
* Проверяет историю до первого полученного сообщения, чтобы не писать в старые переписки. Несколько новых сообщений подряд не мешают автоответу.
* Игнорирует каналы, группы и других ботов.

---

## 🔑 Шаг 1. Получение API_ID и API_HASH (1 минута)
1. Перейдите на официальный портал Telegram: **[my.telegram.org](https://my.telegram.org)**.
2. Введите свой номер телефона и код из Telegram.
3. Нажмите **API development tools**.
4. В поле *App title* и *Short name* введите любые слова (например, `responder`).
5. Нажмите *Create application*.
6. Скопируйте два значения: **api_id** (число) и **api_hash** (строка).

---

## ☁️ Шаг 2. Бесплатный хостинг 24/7 (3 лучших варианта)

### Вариант 1: Koyeb (Рекомендуется, 100% бесплатно 24/7)
1. Зарегистрируйтесь на **[koyeb.com](https://www.koyeb.com)** (бесплатный тариф Eco Nano).
2. Создайте GitHub-репозиторий и загрузите туда файлы из этой папки (`tg-auto-responder`).
3. В Koyeb нажмите **Create Service** -> выберите свой репозиторий.
4. В разделе **Environment Variables** укажите:
   - `API_ID`
   - `API_HASH`
   - `BOT_USERNAME`
   - `SESSION_STRING` (получите его через команду `python login.py` на ПК)
5. Нажмите **Deploy** — скрипт будет работать 24/7 бесплатно!

---

### Вариант 2: Hugging Face Spaces (Бесплатно навсегда, без карты)
1. Зарегистрируйтесь на **[huggingface.co](https://huggingface.co)**.
2. Перейдите в **Spaces** -> **Create new Space**.
3. Выберите **Docker** (Blank) -> лицензия Apache 2.0 -> Private.
4. Загрузите файлы: `Dockerfile`, `requirements.txt`, `main.py`.
5. В **Settings** -> **Variables and secrets** добавьте переменные:
   `API_ID`, `API_HASH`, `BOT_USERNAME`, `SESSION_STRING`.
6. Спейс запустится и будет работать 24/7 в фоне!

## 💻 Локальный запуск на компьютере

Установите зависимости:
```bash
pip install -r requirements.txt
```
Запустите вход:
```bash
python login.py
```
После входа запустите скрипт:
```bash
python main.py
```

## Проверка и диагностика

Проверка обработчика без подключения к Telegram и без отправки сообщений:

```bash
python -X utf8 -m unittest -v test_responder test_application
```

На Render в **Logs** должны появиться строки об успешной авторизации и активности
автоответчика. `/health` возвращает 200 только после авторизации и при подключении
к Telegram; до подключения и при его потере — 503.

Логи различают старую переписку, уже отправленный ответ и ошибку запроса или отправки.
Запись пользователя в `replied_users.json` происходит после успешной отправки.
Не добавляйте `session_string.txt`, `.env` и файлы Telegram-сессий в GitHub.

**Render Free не обеспечивает постоянную работу автоответчика:** сервис засыпает
после 15 минут без входящих HTTP-запросов или WebSocket-трафика и просыпается от
нового веб-запроса. Сообщение в личном Telegram само по себе не является запросом
к веб-сервису. Локальные файлы, включая `replied_users.json`, теряются при
перезапуске или новом развёртывании. См. [ограничения Render Free](https://render.com/docs/free).
Для непрерывной работы необходим постоянно работающий процесс; для сохранения
списка ответов между перезапусками — постоянное хранилище.

Если приложение запущено из Docker, в образ должны попасть `main.py` и `responder.py`.
